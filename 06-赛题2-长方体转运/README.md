# 06-赛题2-长方体转运（`POST /api/task2/execute`）

## 规则与判分（对着 PDF 原图核对过）

- 左侧 4 个固定槽，各有一个带唯一数字（1–4，**每面都有数字**）的长方体；**严格按 1→2→3→4** 抓到右侧指定台面。一次接口调用干完全部。
- 判分：每个 22 分 = 抓起并离开槽 4 + 顺序正确 6 + 放到台面 8 + 放置姿态与槽内一致 4；设备保护 12（磕碰一次 -3）。碰撞致损 = 任务失败。

## 文件

- `task2_blocks.py` — 数字块检测 + Tesseract OCR（与 `04-相机/vision/task2.py` 同源副本）
- `test_task2_synthetic.py` — 合成图测试（用本机 Tesseract）

## 动作序列（单块，外层循环数字 1→2→3→4）

1. 拍照识别：检测 4 个长方体 → OCR 数字 → 建"数字→槽位"映射（没把握就重拍，**绝不猜**）；
2. `end_effector` 到槽位上方安全高度 → `set_pos` 张手；
3. 直线下降到抓取高度 → `set_pos`/`set_pvc` 夹持（grasp_digit 手型）→ 电流/位置确认夹稳；
4. 直线抬起离槽（4 分到手）→ 移到台面落点上方 → 下降 → 松手 → 抬走；
5. 落点姿态照搬槽内朝向（还有 4 分姿态分）。

单块失败：换参数重试 N 次，仍失败返回 `success:false` 把机会留给第二次演示。每条运动指令 60s 上限，动作拆小。

## 审查结论（2026-08-16）

合成图测试 5 项全过：数字 1/2/3/4 单图全识别对；四块同图检出 4 个候选且数字为 {1,2,3,4}。
