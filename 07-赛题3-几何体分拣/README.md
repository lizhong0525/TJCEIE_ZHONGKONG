# 07-赛题3-几何体分拣（`POST /api/task3/execute`）

## 规则与判分（对着 PDF 原图核对过）

- 左侧随机姿态放 4 个几何体（长方体/正方体/多面体/圆柱体等；平躺/侧立/翻转/倾斜都有可能）。右侧 4 个固定槽，外侧标注形状名称。识别形状 → 按随机位姿自适应抓取 → 抓起后校正姿态 → 端正放入**同名槽**，4 个全做完（不要求顺序）。
- 判分：每个 22 分 = 抓起离开初始区域 6 + 放入同名槽 12 + 主体完全进工位边界 4（压线/悬外不得分）；安全防护 12（磕碰一次 -3）。碰撞致损 = 任务失败。

## 文件

- `task3_shapes.py` — 2D 形状分类（圆度/顶点数/长宽比；与 `04-相机/vision/task3.py` 同源副本）
- `test_task3_synthetic.py` — 合成图测试

## 动作序列（单个几何体，循环 4 次）

1. 拍照（要深度）→ 分割 4 个物体 → 形状分类 + 位姿估计（至少主轴方向）；
2. 按姿态选抓取策略（平躺上夹/侧立侧夹/圆柱抱抓），必要时先拨正（题目允许"调整几何体角度"）；
3. 抓起离开初始区域（6 分）→ 空中用手腕（`/api/joints` 调 wrist 或 `end_effector` 改 RPY）校正姿态；
4. 落点取槽中心，到位再松手，保证主体完全入槽（4 分）；
5. 中途掉落 = 该物体不得分，**继续做剩下的**，不整体中止。

槽位是固定的：赛前人工记录"形状名→槽位"对应表即可，不用识别槽上文字。可自备 1 张位置标定贴纸（规则允许）。
