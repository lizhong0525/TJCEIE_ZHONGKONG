# 现场标定说明（中控杯复赛）

官方图纸**不给任何尺寸**：台面尺寸、按钮坐标、槽位坐标全部要现场自己获得。
本方案走两条路线，结果都写进同一个文件 `config/site.yaml`：

- **主路线 · 视觉标定**：相机 + 深度自动算出按钮/槽位/台面坐标
  （工具 `tools/vision_calibrate.py`，开发中）。
- **备路线 · 人工标定**：卷尺/直尺量完后交互式录入，命令：

  ```
  python -m tools.calibrate
  ```

两条路线互为兜底；视觉路线跑不通时，用人工路线把 `site.yaml` 填满即可上场比赛。

## 交叉校验阈值（★ 现场可改的参数）

视觉标定结果会与人工测量（或视觉两次互测）对比，偏差超过阈值就**拒绝写盘并报警**，
防止带着错坐标上场。

| 配置项 | 位置 | 单位 | 默认值 |
| --- | --- | --- | --- |
| `cross_check_tol` | `config/site.yaml` → `calibration:` 段 | 米 (m) | `0.005`（5 mm） |

**现场调整方法**：用文本编辑器打开 `config/site.yaml`，改 `cross_check_tol` 的数值
（例如想放宽到 1 cm 就写 `0.01`），保存后**重启算法服务**生效。不用改任何代码。

代码侧读取入口：`SiteConfig.calibration.cross_check_tol`（`algorithm_service/config.py`）。

## 安全区 `safe_box`

安全区（机械臂允许活动的范围）**只走人工录入**，不信视觉，开赛准备阶段量一次填好即可。
