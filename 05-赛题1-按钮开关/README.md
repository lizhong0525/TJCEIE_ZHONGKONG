# 05-赛题1-按钮开关（`POST /api/task1/execute`）

## 规则与判分（对着 PDF 原图核对过）

- 面板 3 个灯，每灯下方 1 个开关（共 **2 个按钮 + 1 个拨动**）。竞赛软件随机点亮一个灯 → 调你一次接口 → 你操作**亮灯下方对应的开关**。共 3 次（3 个灯各亮一次）。
- 判分：每正确完成一个 30 分 ×3 = 90；设备保护 10（轻微磕碰一次 -3）。碰撞致形变/移位/损毁 = 任务失败。

## 文件

- `task1_lamp.py` — 亮灯检测（HSV 亮度+饱和度打分，双阈值；与 `04-相机/vision/task1.py` 同源副本）
- `test_task1_synthetic.py` — 合成图测试

## 动作序列（接入 01-算法服务的流程）

1. 自检：臂 `healthy/enable`，手 `errors` 全 0；
2. `POST /api/end_effector` 到标定好的"拍照位"（`cartesian_linear`，慢速）；
3. 拍照 → `detect_lit_lamp` 判定哪个灯亮（ROI 未标定/全暗/并列都会**拒绝**，这是安全设计）；
4. 查表得开关 world 坐标和类型：
   - 按钮：到开关正前 5–10cm → `set_pos` 单指伸出（tap 手型）→ 小幅直线压入几 mm → 原路后退 → 收指；
   - 拨动：接触 → 沿拨动方向一小段 `cartesian_linear` → 撤离；
5. 撤回安全位 → 返回 `{"success":true,"message":"task1 ok"}`。

**铁律：无状态。** 不记"上次灭了哪个灯"，每次调用重新拍照判断（软件连调 3 次，每次随机）。

合成图测试 6 项全过：三 ROI 各亮一次全选对、全暗拒绝、并列拒绝、未标定拒绝。
