# 相机模块

请从 [使用说明.md](使用说明.md) 开始。第一次无相机也可以双击 `运行离线自检.bat`。

本模块与根目录 Flask 文档问答服务相互独立：安装相机专用依赖不会改变现有服务。
第一次使用先将 `config.example.json` 复制为 `config.json`；真实机械臂地址和现场标定结果不会提交到 Git。

推荐顺序：

```text
检查相机 → 导出内参 → 采集手眼样本 → 求解手眼 → 拟合台面 → 调任务识别
```

当前仓库可见分支还没有 `algorithm_service/` 和 `config/site.yaml` 的实际代码，因此本模块先输出
`results/*.json`。待主算法配置结构提交后，再做最后一层字段映射；不能仅凭文档猜测字段名后直接控制真机。
